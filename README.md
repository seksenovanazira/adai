# Цифровой наряд — локальная демонстрация

## Запуск

Распакуйте ZIP целиком. Дважды щёлкните `index.html` — он откроется в современном Edge, Chrome или Firefox. Интернет, установка пакетов и сборка не нужны. Все файлы должны оставаться в одной папке.

## Как проверить полный сценарий

1. Инициатор по умолчанию — Адай Сейсенов. Добавьте исполнителей через поиск по имени или табельному номеру, например «1002». Повторно добавить человека нельзя.
2. Выберите вид работ, заполните объект, адрес, описание, руководителя и даты. Для «Другие работы» заполните уточнение.
3. Пример периода: 25.09.2026–01.10.2026 — 5 рабочих дней. До 02.10.2026 — 6, отправка запрещена. Даты считаются включительно, исключаются только субботы и воскресенья, праздники не учитываются. Период только из выходных запрещён.
4. «Сохранить черновик» допускает незаполненную форму. «Отправить на согласование» проверяет все обязательные данные и сохраняет документ.
5. В верхнем списке пользователей выберите Руслана Ахметова и нажмите «Согласовать и подписать». Затем переключитесь на Тимура Алиева, после него — на Сауле Муратову для финального подписания. Ответственный руководитель задания выбирается отдельно и не меняет организационную цепочку инициатора.
6. Для отклонения текущий согласующий должен указать причину. Вернитесь к Адаю, исправьте данные и отправьте повторно. Согласование начнётся заново; история прежних решений останется.
7. После финальной подписи поля заблокированы. Адай может нажать «Завершить работы». Подписи, статусы и история сохраняются при перезагрузке.
8. «Новый наряд» создаёт документ от имени тестового инициатора. Сохранённые документы доступны в верхнем списке.

Данные хранятся в localStorage текущего браузера. При очистке данных браузера, смене браузера или переносе папки сохранённые записи могут стать недоступны. Используйте одну вкладку; синхронизации между вкладками и компьютерами нет. Если браузер запретит хранилище, приложение покажет ошибку сохранения.

## Файлы и замена HR

- `index.html`, `styles.css`, `app.js` — интерфейс и сохранение.
- `hr.js` — 12 вымышленных сотрудников с табельными номерами и managerId. Асинхронные методы listEmployees, getCurrentUser, searchEmployees отделены от интерфейса; get возвращает сотрудника из локального справочника. Для реальной интеграции замените адаптер API и загрузку справочника.
- `logic.js` — проверка дат и обязательных полей, маршрут, переходы статусов и права демонстрационных ролей.
- `test.cjs` — проверки логики. Если установлен Node.js: `node test.cjs` из папки проекта.
- `server.cjs` — необязательный локальный сервер. С Node.js выполните `node server.cjs`, затем откройте http://127.0.0.1:8087. Остановка: Ctrl+C.

Это демонстрация, а не производственная система: переключатель ролей заменяет вход, «подпись» — тестовая запись без криптографии и юридической силы. Для эксплуатации нужны серверная авторизация и проверка прав, HR API, база документов, доверенная ЭП и неизменяемый аудит. Не вводите реальные персональные данные.
